# Shelly Beach in 3D

Unofficial 3D walk-through of the Shelly Beach, Manly foreshore renewal concept plan (Northern Beaches Council, L-001, 28/09/2026), by Marco Bordieri for the [Swim Manly App](https://app.viz.net.au/Manly-Swim/).

Live: https://app.viz.net.au/Shelly-Beach-3D/

Shapes and positions come from the council plan file; heights, tree and furniture forms are estimates.
